## 🚀 Featured Patterns

*   **[Automated SRE Incident Remediation](https://github.com/jonathanscholtes/azure-sre-agent-github-demo)**  
    A self healing pipeline showcasing automated incident detection and governance. Takes a failure spike down to an automated code fix and a merged GitHub PR with minimal human friction.
    *   **Key Patterns:** Agentic reliability, autonomous remediation loops, GitHub Copilot integration.

*   **[Azure AI Foundry Agentic Workshop](https://github.com/jonathanscholtes/azure-ai-foundry-agentic-workshop)**

*   **[BrandSense | Multi Agent Brand Intelligence](https://github.com/jonathanscholtes/Azure-AI-Foundry-BrandSense)**

*   **[Contract Risk Analysis | MCP + Azure AI Foundry](https://github.com/jonathanscholtes/contract-risk-mcp-foundry)**  
    Structured, auditable legal tech workflows leveraging the Model Context Protocol (MCP) for secure tool execution and external data access.
    *   **Key Patterns:** Tool based evaluation isolation, auditable decision trees.

*   **[ITSM Multi Agent System | Automated Operations](https://github.com/jonathanscholtes/Azure-AI-Foundry-ITSM)**  
    Enterprise IT Service Management driven by autonomous agent layers covering intelligent classification, context aware routing, and full lifecycle handling.

*   **[Agents Audit System | Observability & Evaluation](https://github.com/jonathanscholtes/Azure-AI-Foundry-Agents-Audit)**  
    A dedicated framework built to track tool usage, execution flow, and agent decisions in real time to drive consistent operational outcomes.
    *   **Key Patterns:** Agentic tracing, runtime evaluation, LLM as a judge observability.
